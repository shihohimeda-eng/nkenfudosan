# ファクトチェックルール

## 確認対象

住宅価格、金利、税制、ローン、市況など事実確認が必要な内容は必ず確認します。特に数字、年月日、市場データ、法律、制度、税制、金利、住宅ローン、売買価格を対象にします。

## 確認の原則

1. 可能な限り一次情報へ遡る。優先情報源は[sources.md](sources.md)を参照。
2. 主張と出典を対応させ、データ時点と対象地域を記録する。
3. 確認できない場合は推測で補完せず、「確認できませんでした」と報告する。
4. 事実と推測を明確に分ける。推測は何が推測か、なぜそう考えたかを報告する。
5. 動画内で推測を事実として断定しない。
6. 正確性に必要な条件は、速い編集や短いテロップのために削らない。必要に応じて小テロップや注釈で示す。

本人の実体験に関する具体的な数字や発言も、入力された資料の範囲を超えて補いません。元仕様に背景として記載されていることと、公開用の主張が検証済みであることは区別します。

## 判定

| 判定 | 意味・出力 |
| --- | --- |
| 確認済み | 主張を支える資料を確認できた。出典、データ時点、対象地域を示す |
| 確認できず | 必要な裏付けを確認できない。「確認できませんでした」と明記 |
| 推測 | 事実そのものではない。推測の内容と理由を明示 |

未確認の主張を確認済みに変更するために、出典や日付を創作してはいけません。確認できない点が残る場合は、完成版でもその状態を明示します。

## FACT CHECK出力

台本本文とは別に、主張ごとに次の形式で出力します。

- 主張：
- 判定：確認済み／確認できず／推測
- 出典：資料名とURL、または提供資料の識別情報
- データ時点：
- 対象地域：
- 補足：条件、確認できない点、推測の内容と理由など

資料名とURL等の併記は、元仕様の「出典」を追跡可能にするための記録方法です。データ時点や地域が不明の場合は「不明」、該当しない場合は「該当なし」とし、埋め合わせません。

## 表現上の制約

断定を強める方針でも、根拠のない断定や利益・値上がりの保証は禁止です。「絶対儲かる」「必ず値上がりする」「今買わないと手遅れ」などは使用しません。その他のNG表現は[requirements.md](requirements.md)を参照。

## 未確定事項

- データを何年前まで許容するか、公開前の再確認時期
- 本人の専門領域・非専門領域と専門家確認の範囲
- SNS投稿の引用可否、情報源の採否に関する追加条件
- 未確認の主張を含む案の公開判断者と具体的な承認基準
- 訂正、削除、再投稿、謝罪、法務確認の担当・手順

これらは[account-owner-interview.md](account-owner-interview.md)で確認します。本ファイルは検証の運用仕様であり、個別の制度・金利等について今回最新情報を調査した記録ではありません。
