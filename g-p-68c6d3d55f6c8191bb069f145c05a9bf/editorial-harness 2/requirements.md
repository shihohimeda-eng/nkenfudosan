# 要件・編集方針

状態：元会話の最終仕様書に基づく整理済み要件。未確定事項は末尾に明記します。

## 目的と成果

対象は住宅購入をテーマにしたSNSショート動画。基本尺は60秒です。

- フォロワー増加とフォロワー教育
- 勉強会への参加
- 最終的な住宅購入の検討

「自分も家を買えるかもしれない」「住宅購入という選択肢がある」「家についてもっと勉強したい」と思える内容を目指します。

| 時間軸 | 視聴後の理想状態 |
| --- | --- |
| 短期 | フォローする、他の投稿を見る、住宅について学ぶ |
| 中期 | 勉強会へ参加する、購入について具体的に考える |
| 長期 | 自分に合った住宅購入を実行する |

購入を無理に推奨せず、視聴者自身が判断できる状態を作ります。

## ターゲット

知識レベルは基本的に初心者です。

| 層 | 主な認識・悩み | 伝えること |
| --- | --- | --- |
| 潜在 | まだ早い、賃貸でよい、購入を考えたことがない | 住宅購入も人生の選択肢のひとつ |
| 準顕在 | いつか買いたい、自分に買えるかわからない、損が怖い、難しそう | 正しい知識を持ち、判断できる状態になること |
| 顕在 | そろそろ考えている、何を買えばよいかわからない、失敗したくない | 購入判断の基準 |

共通の悩みは、住宅購入への怖さ、賃貸以外の選択肢への理解不足、購入可能性や購入後の未来がわからないこと。知りたい内容はメリット・デメリット、購入可能性、購入後の未来、住宅ローン、資産価値、売却、住み替えです。

## 編集判断の優先順位

1. 正しい情報
2. エヌケンの思考
3. 視聴者にとってのわかりやすさ
4. SNS上での視聴維持
5. 情報量

中心に置くのは「家を購入した後の未来」。暮らし、お金、選択肢、資産、住み替え、将来まで想像できる内容にします。原則は1動画1メッセージ。詳細を詰め込まず、もっと知りたいと思える余白を残します。

## 編集テンポと動画構成

速めのテンポで、冒頭フック、視聴維持、情報理解、CTAの順に編集上の重点を置きます。この順位は正確性を下げる許可ではありません。

| 秒数 | 役割 | 要件 |
| --- | --- | --- |
| 0〜3 | HOOK | 強い結論、違和感、意外性、数字、ベネフィット、疑問、損失回避。前置き禁止 |
| 3〜10 | 結論 | 何を伝える動画かをすぐ示す |
| 10〜25 | 理由 | 基本1〜3個。細かすぎる説明は避ける |
| 25〜45 | 具体例 | 本人の経験、購入・売却・リノベ事例、データや数字を可能な限り使う |
| 45〜55 | 未来 | 視聴者の生活や購入判断がどう変わるかを示す |
| 55〜60 | CTA | 基本はフォロー。フォローする理由を短く提示 |

特に3〜15秒で離脱を防ぎます。1〜3秒ごとを目安にカット、画角、テロップ、Bロール、画像、図解、SE、拡大、強調などの意味ある変化を入れます。数字や図解の理解には必要な時間を取り、意味のない演出変更はしません。

情報の連鎖：HOOK → 結論 → 新しい疑問 → 理由 → 具体例 → 新しい発見 → 未来 → フォロー。

中間フックの例：「ただ、ここに落とし穴があります」「僕も買う前は勘違いしてました」「実際に売って初めてわかりました」。経験を語る表現は、その本人の経験が確認できる場合に使用します。

重複説明、前置き、細かすぎる補足、本筋から外れる情報、専門的すぎる説明、今知らなくても困らない情報は削ります。正確性に必要な条件は削らず、必要に応じて小テロップや注釈に回します。

## テロップ・文章・CTA

- 主要テロップは原則7〜12文字程度。1テロップ・1画面1メッセージ。
- 長文を読ませず、漢字で自然に表現できるものは漢字を優先。
- 専門用語は使用可能だが、初心者向けの短い説明を添える。
- 断定強め、簡潔、初心者にもわかる文章。偉そうにせず、他者を否定せず、過度に不安を煽らない。
- 基本CTAはフォロー。「家購入を勉強したい人はフォロー」など理由を示す。
- 勉強会への直接導線は必要な動画のみ。具体的な適用条件・導線は未確定。

## NG表現

「馬鹿」「情弱」「賃貸は負け」「買わないと損」「絶対儲かる」「必ず値上がりする」「今買わないと手遅れ」「○○な人は終わっている」。

人を蔑む表現、属性否定、根拠のない断定、過剰な恐怖訴求も禁止します。

## 入力

テーマ、キーワード、取材メモ、社内資料、一次情報、参考URL、競合コンテンツ、商品・サービス情報、本人の実体験を利用します。主なキーワードは「住宅購入」。未提供の情報は創作しません。
