# アカウント保有者への確認項目

状態：ヒアリング用の確認票です。質問として挙がった例は、採用済みの運用や本人の回答を意味しません。「整理済み」は元会話の仕様書に記載された内容です。

## 最優先の10項目

| 項目 | 整理済みの内容 | 未確定・追加確認 |
| --- | --- | --- |
| 1. 目的 | フォロワー増加・教育、勉強会参加、住宅購入検討 | 事業成果との対応、SNSが担う範囲 |
| 2. KPI順位 | フォロー率 → 完視聴率 → 保存率 → 勉強会遷移率 | 目標値、分母、計測方法、評価期間 |
| 3. ターゲット | 住宅購入の初心者。潜在・準顕在・顕在 | 年齢、属性、各層の比重 |
| 4. 本人の思想 | 購入後の未来を伝える編集方針 | 本人固有の思想10項目、根拠資料 |
| 5. 実体験・実績 | 購入・リノベ・売却経験等が仕様書に記載 | 具体的な経緯・数字・証拠・公開可否 |
| 6. NG事項 | 侮蔑、属性否定、根拠のない断定、過度な煽り等は禁止 | NGテーマ、競合比較、非公開情報 |
| 7. 情報源基準 | 一次情報優先、未確認を推測で埋めない | 鮮度基準、引用可否、専門家確認範囲 |
| 8. キャラクター | 簡潔、初心者向け、偉そうにしない | SNS上で見せたい人物像 |
| 9. CTAと導線 | 基本は理由を添えたフォロー、必要時のみ勉強会 | LP・LINE・申込先等の具体的導線 |
| 10. 承認基準 | AI自己レビューを1回行う | 最終承認者、OK・修正・ボツの基準、期限 |

## 詳細ヒアリング30項目

以下は元会話の質問項目を再構成したものです。既に整理済みの部分は再質問せず、不足部分を確認します。

| No. | 確認項目 | 質問・記録する内容 |
| --- | --- | --- |
| 1 | 最終目的 | フォロー、問い合わせ、来店、勉強会、購入、採用、認知などのうち何を目指すか |
| 2 | KPI | 優先順位を維持するか。目標値、計測方法、評価基準は何か |
| 3 | 届けたい相手 | 年齢・属性・悩み・知識レベル・検討段階。どの状態へ変えたいか |
| 4 | 本人の思想 | 信じていること、業界への違和感、伝えたいこと、常識への反論、正しい判断の定義 |
| 5 | 言いたくないこと | NGワード、批判したくない対象、政治・宗教・価値観、競合名や他社比較の可否 |
| 6 | 断定の強さ | 条件付きの話し方、「人による」の扱い、煽りの許容範囲。既存NGルールは維持 |
| 7 | 実体験 | 成功、失敗、購入、売却、リノベ、顧客事例、数字で話せる実績、意思決定の背景 |
| 8 | 公開可能情報 | 年収、売上、利益、物件・購入・売却価格、家族・顧客情報、顔出し、実名、住所・エリア |
| 9 | 公開禁止情報 | NDA対象、顧客秘密、社内・金融情報、未発表案件、個人情報 |
| 10 | 情報源基準 | 公的機関・業界メディア・経験談の扱い、SNS引用、データの許容年数 |
| 11 | 専門領域 | 税務、法務、ローン、投資、建築、リノベ、売却のどこまで話せるか。非専門領域は何か |
| 12 | 動画トーン | 先生、友人、兄貴、冷静分析、エンタメ、辛口、親しみ型など、どれを目指すか |
| 13 | 人物像 | 実際の本人とSNS上の見せ方を分け、知性・親しみ・実践者・専門家・誠実さ等を確認 |
| 14 | 差別化 | 経歴、実績、思想、説明力、データ、スピード、人柄、顧客層、商品設計 |
| 15 | 競合・参考 | URLだけでなく、好きな構成・編集・キャラ・フックと、真似したくない点 |
| 16 | 扱いたいテーマ | 教育、ノウハウ、体験談、ビフォーアフター、市況、ニュース、FAQ、誤解解消、失敗談 |
| 17 | 扱いたくないテーマ | 16とは別に、除外するテーマと理由を確認 |
| 18 | CTA順位 | フォロー以外のコメント、保存、DM、LINE、勉強会、問い合わせ、購入の扱い |
| 19 | 売り込み | CTAの頻度、教育投稿の扱い、セールス投稿の比率、勉強会を直接訴求する条件 |
| 20 | 顧客導線 | SNSからプロフィール、LP、LINE、勉強会、個別相談、契約へ進む実際の経路 |
| 21 | 顧客の反論 | 高い、怖い、まだ早い、自分には無理、他社比較したい、今でなくてよい、賃貸で十分等 |
| 22 | よくある質問 | 営業・勉強会・DMで実際に聞かれた質問を収集 |
| 23 | 顧客の勘違い | 誤解・思い込み・購入を妨げる誤認。常識破壊系企画の素材にする |
| 24 | 成約者 | 何を理解すると動くか、決め手、不安が消える場面 |
| 25 | 非成約者 | 離脱地点、引っかかる点、怖さ、誤解 |
| 26 | 本人レビュー | OK・修正・ボツの条件と具体例 |
| 27 | 承認権限 | 最終承認者は誰か。本人・広報・法務・経営・営業の役割 |
| 28 | 修正と期限 | 初稿提出日、返答期限、修正可能回数、緊急投稿の判断者 |
| 29 | 炎上・訂正 | 返信、対応しない判断、コメント削除、投稿削除、訂正、再投稿、謝罪、法務確認の方針 |
| 30 | 評価期間 | 1投稿、1週間、1か月、3か月など、成功・失敗を判定する期間 |

## 導線の確認

会話中の例：SNS → プロフィール → LP → LINE → 勉強会 → 個別相談 → 住宅購入・契約。

これは確認用の候補であり、実装済みの導線ではありません。実際に使用する経路、各URL、SNSのゴール地点は未確定です。
